# 學生成績自動計算表

這是一個可在任何電腦使用的 Excel 成績計算表，自動計算平均分與級距。

## 功能
- 29 位學生
- 5 科成績：國語、數學、社會、自然、英語
- 每一科都有自己的級距
- 未滿 60 分的分數自動以紅字顯示
- 自動計算個人平均與平均級距
- 全班各科平均
- 平均級距人數統計

## 使用方式
1. 下載 `student_scores.xlsx`
2. 用 Microsoft Excel、LibreOffice Calc 或其他相容軟體開啟
3. 在藍色字體欄位輸入分數
4. 各科級距、平均與級距會自動更新
5. 未滿 60 分的分數會自動變成紅字

## 級距標準（六個級距）
- 100 分：100
- 90-99 分：90-99
- 80-89 分：80-89
- 70-79 分：70-79
- 60-69 分：60-69
- 未滿 60 分：未滿60

## 下載
請下載倉庫中的 `student_scores.xlsx` 檔案即可使用。

適用於任何安裝 Excel 相容軟體的電腦。
